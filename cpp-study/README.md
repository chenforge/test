# C++ 研习室

面向第一次学编程的学生，以 C++17 为核心，覆盖大学 C++ 课程的基础语法、函数与递归、容器、引用和指针、资源管理、类与对象、继承多态、模板、STL、文件和工程实践。C++20 内容另行注明。

## 打开网站

直接双击本文件夹里的 `index.html`，使用 Chrome、Edge、Firefox 或 Safari 打开。不需要安装网站运行依赖，也不需要启动服务器。网站的页面、课程、脚本、样式及图片都在这个文件夹里，可以整体复制到别的电脑。

网站提供 12 章、48 节课程，每节都有详细讲解、完整示例、常见误区、自测解析和编程练习。代码实验室包含变量、循环、指针、递归、二分查找、冒泡排序和对象七种逐行演示。

## 怎样学

1. 从“程序与工具”开始，先预测每段示例的输出，再阅读解释。
2. 遇到有演示的课程，修改输入后逐步观察状态，试着说明每一步的原因。
3. 先独立回答自测，再对照解析。练习本可以筛选未做、答对及需要复习的问题。
4. 在草稿本里写自己的答案，需要时展开提示。草稿与学习进度保存在当前浏览器；清除浏览器数据会删除这些本地记录。
5. 下载 `.cpp` 草稿，在本地编译器里编译运行。编译环境配置位于第 1 章第 2 课。

代码实验室演示的是固定示例的执行过程，**不是通用 C++ 编译器**。草稿本保存和导出代码，不会假装编译或给出未经执行的运行结果。教学示例中的内存地址为示意编号。

## 文件

- `index.html`：网站入口
- `styles.css`：桌面、手机及打印样式
- `app.js`：课程导航、搜索、阅读、自测、草稿和进度
- `content-foundation.js`：第 1–6 章
- `content-university.js`：第 7–12 章
- `lab.js`：七种代码逐步演示
- `assets/`：网站图标；本地文件夹另保留设计参考与实际页面截图

运行网站时不请求第三方字体、脚本或图片。搜索覆盖课程标题和正文；快捷键 `Ctrl+K`（Mac 用 `Command+K`）打开搜索，`Esc` 关闭。正文支持调整字号和打印。

## 内容参考与边界

讲解是为初学者重写的教学材料，技术规则参考 [ISO C++ 工作草案](https://eel.is/c++draft/) 和 [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines)。课程中的类比用于理解，并在指针、生命周期、虚函数等位置说明了边界。

网站提供大学 C++ 核心课程的学习路线；计算机专业的操作系统、网络、数据库、编译原理及系统化的数据结构课程仍需单独学习。C++20 是扩展内容，核心练习按 C++17 编译。文件读写示例需要运行目录可写。
